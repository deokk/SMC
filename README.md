### 🚲 따릉이 개인 맞춤형 통합 스마트 모바일 앱 프로젝트
## 1. 프로젝트 개요

**목표**: 서울시 공공자전거 ‘따릉이’ 이용자에게 실시간 현황, 개인화된 이용 정보, 편의 기능을 제공하는 올인원 모바일 앱 개발

**핵심 가치**:

사용자 맞춤형(즐겨찾기)

편리한 데이터 접근(실시간+과거 조회)

확장성 있는 기능 구조(날씨, 소셜, 분석)

## 2. 주요 기능
**✅ 필수 기능 (MVP, 시연용 최소 목표)**

**1. 실시간 현황 조회**

지도에서 대여소 위치 및 자전거/거치대 현황 표시

**2. 즐겨찾기 대여소 관리**

즐겨찾기 등록/삭제, 홈 화면에서 빠른 현황 확인

**3. 과거 데이터 조회 (표 형식)**

어제, 이틀 전, 7일 전의 시간대별 자전거 수를 표로 제공

**🚀 선택 기능 (확장 가능)**

날씨/대기질 표시

마이페이지 (이용 기록, 라이딩 패턴 분석)

소셜 기능 (친구와 위치 공유, 패턴 비교)

## 3. 시스템 구조

**사용자 단말 (모바일 앱)**: React Native/Flutter

**백엔드 서버**: Node.js + Express

**데이터베이스**: MySQL (사용자, 즐겨찾기, 과거 현황 저장)

**외부 데이터**: 서울시 따릉이 API (실시간 현황), 카카오맵 SDK, 기상청/에어코리아 API(선택)

## 4. 기대 효과

사용자 맞춤형 대여소 관리로 편의성 향상

실시간+과거 데이터 제공으로 이용 패턴 이해 가능

날씨, 대기질, 소셜 기능 확장을 통해 서비스 확장성 확보
