### 따릉이 개인 맞춤형 모바일 앱 프로젝트 최종 계획

### **1. 프로젝트 개요**

- **프로젝트명**: 따릉이 개인 맞춤형 통합 스마트 모바일 앱
- **목표**: 서울시 공공자전거 '따릉이' 이용자에게 실시간 현황, 개인 이용 패턴, 안전, 날씨 및 대기질 정보, 대중교통 연계 정보를 종합적으로 제공하는 **올인원 모바일 앱**을 개발합니다.

---

### **2. 핵심 기능**

- **지도 기반 따릉이 대여소 현황**:
    - **카카오맵 SDK**를 사용하여 대여소 위치, 실시간 자전거 및 거치대 수를 한눈에 보여줍니다.
- **정류장별 과거 데이터 조회**:
    - 특정 대여소의 과거 시간대별 대여 및 반납 건수 데이터를 그래프로 제공해 이용 패턴을 파악하게 돕습니다.
- **개인 이용 패턴 분석**:
    - 사용자의 따릉이 이용 기록을 분석하여 주간/월간 이용량 변화, 특정 요일의 이용 습관 등을 보여주는 개인화된 리포트를 제공합니다.
- **스마트 길찾기 및 추천**:
    - '따릉이만', '대중교통만', '따릉이+대중교통' 중 선택해 최적 경로를 제시합니다.
    - **기상청** 및 **에어코리아 API** 데이터를 기반으로 날씨나 미세먼지 상태에 따라 따릉이 이용을 추천/비추천합니다.
    - 과거 데이터를 바탕으로 자전거 확보가 쉬운 최적의 **출발 시간**과 **대체 대여소**를 추천합니다.
- **실시간 위치 공유**:
    - 앱의 GPS 기능을 활용해 따릉이 이용 중인 위치를 미리 지정한 사람에게 공유하여 안전 귀가를 돕습니다.

---

### **3. 필요한 기술 및 API**

- **서울시 열린데이터광장**: 따릉이 관련 모든 데이터(대여소 정보, 실시간 대여 정보, 과거 이용 정보)를 확보합니다.
- **카카오맵 SDK**: 앱 환경에 최적화된 지도 및 길찾기 기능을 제공하는 도구로, 웹 API보다 더 빠르고 안정적인 GPS 위치 추적 기능을 구현할 수 있습니다.
- **기상청 API**: 기온, 강수량 등 날씨 정보를 가져옵니다.
- **에어코리아 API**: 미세먼지, 초미세먼지 등 대기질 정보를 가져옵니다.

---

### **4. 역할 분담 및 기술 스택**

세 명의 팀원이 아래와 같이 역할을 나눠서 프로젝트를 진행합니다.

- **프론트엔드 개발자 (모바일 앱 구현)**
    - **담당 업무**: 앱의 UI/UX 구현, **카카오맵 SDK** 연동, GPS 위치 추적 및 공유 기능, 데이터 시각화.
    - **기술 스택**: **React Native**, JavaScript, React Native Maps, Axios.
- **백엔드 개발자 (서버 로직 및 데이터 관리)**
    - **담당 업무**: Flask를 이용한 API 서버 구축, 외부 API 연동, PostgreSQL 데이터베이스 관리, 추천 로직 및 개인 분석 알고리즘 구현.
    - **기술 스택**: **Python(Flask)**, PostgreSQL, Pandas, NumPy, requests.
- **프로젝트 매니저 & 데이터 분석가 (기획 및 데이터 분석 총괄)**
    - **담당 업무**: 프로젝트 기획 및 일정 관리, 따릉이 과거 데이터 분석 및 가공, 핵심 알고리즘 설계 지원, 품질 관리.
    - **핵심 도구**: SQL, 데이터 시각화 툴.
